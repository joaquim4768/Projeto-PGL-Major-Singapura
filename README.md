# Projeto-PGL-Major-Singapura
Projeto do IFPE da cadeira de Web I. Criação de um site de divulgação de um Evento, escolhi o Major de Counter-strike e desenvolvi um site com base nele.

Foram implementados conceitos como flexbox e grid-layout como principal forma de organização do layout do site.

Utilizados também conceitos de animação utilizando :hover e transition.
